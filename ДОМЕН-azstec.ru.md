# Переезд на домен azstec.ru — инструкция на понедельник

Всё в проекте уже подготовлено. В понедельник останется прописать DNS и нажать пару кнопок.
Ниже — точный порядок действий и важные предупреждения.

---

## Что подготовлено заранее

| Файл | Что делает |
|---|---|
| `подключить-домен.bat` | Создаёт файл `CNAME` (домен `azstec.ru`) и публикует его на GitHub |
| `tools/set-domain.ps1` | Логика этого ярлыка |
| `robots.txt` | Разрешает индексацию, закрывает служебные страницы (admin, cart, checkout), указывает карту сайта |
| `sitemap.xml` | Карта сайта из 21 страницы с адресами `https://azstec.ru/...` |
| `.nojekyll` | Уже был — GitHub отдаёт файлы «как есть» |

Сайт статический, все внутренние ссылки относительные, поэтому после привязки домена
ничего менять не нужно — сайт откроется прямо с корня `https://azstec.ru/`.

---

## ⚠️ Прежде чем начать — важное

1. **Старый сайт на azstec.ru перестанет открываться.** Как только DNS переключим, домен
   будет показывать новый сайт. Это и есть цель (вы выбрали «заменить старый сайт»).
2. **Порядок критичен:** сначала DNS, потом запуск ярлыка. Если запустить ярлык раньше,
   `amogusas.github.io/azstec-deploy/` начнёт перенаправлять на `azstec.ru`, который ещё
   не настроен — и сайт временно станет недоступен.
3. **Не запускайте `подключить-домен.bat` до готовности DNS** (шаг 2).

---

## Шаг 1. Прописать DNS-записи у регистратора (nic.ru)

Домен `azstec.ru` обслуживается на **nic.ru**. Зайдите в панель управления DNS
(«Мои домены» → azstec.ru → **DNS-серверы и зона** / «Управление зоной»).

### 1.1. Основные записи для GitHub Pages

**Для корня `azstec.ru`** — добавьте/замените **четыре A-записи** (имя `@` или пустое):

| Тип | Имя | Значение |
|---|---|---|
| A | @ | `185.199.108.153` |
| A | @ | `185.199.109.153` |
| A | @ | `185.199.110.153` |
| A | @ | `185.199.111.153` |

**Для `www.azstec.ru`** — одну **CNAME**-запись:

| Тип | Имя | Значение |
|---|---|---|
| CNAME | www | `Amogusas.github.io` |

> Если у домена уже есть старые A-записи (на прежний хостинг) — их нужно **удалить**
> или заменить на эти четыре.

### 1.2. Подтверждение владения доменом (TXT)

GitHub попросит подтвердить, что домен ваш. Добавьте **TXT**-запись:

| Тип | Имя | Значение |
|---|---|---|
| TXT | `_github-pages-challenge-Amogusas` | (код покажет GitHub на шаге 4) |

Точное значение кода GitHub покажет на странице *Settings → Pages* (кнопка **Verify**).
Можно сначала сделать шаг 4, скопировать код, затем вернуться и добавить TXT.

### 1.3. Сохранить

Сохраните зону. Обновление DNS обычно занимает от 15 минут до нескольких часов
(иногда до 24 часов).

---

## Шаг 2. Дождаться, что DNS указывает на GitHub

Проверить можно здесь (просто открыть в браузере):

- https://dnschecker.org → ввести `azstec.ru`, тип **A** → значения должны стать
  `185.199.108.153 … 111.153`.
- Или запустить в терминале: `nslookup azstec.ru 8.8.8.8`

Дождитесь, пока записи начнут отдавать адреса GitHub. Только после этого — шаг 3.

---

## Шаг 3. Запустить ярлык подключения домена

Двойной клик по **`подключить-домен.bat`** в папке проекта.

Он:
- создаст файл `CNAME` со значением `azstec.ru`;
- зафиксирует и опубликует изменение на GitHub.

---

## Шаг 4. Включить домен и HTTPS в GitHub

1. Откройте **https://github.com/Amogusas/azstec-deploy/settings/pages**
2. В поле **Custom domain** введите `azstec.ru` → **Save**.
3. Если появится предупреждение о подтверждении владения — скопируйте код из блока
   **Add a verified domain** и добавьте его как **TXT**-запись у регистратора
   (`_github-pages-challenge-Amogusas`), затем нажмите **Verify**.
4. Дождитесь галочки и включите **Enforce HTTPS**.

---

## Шаг 5. Проверить

Откройте:

- https://azstec.ru — главная
- https://azstec.ru/news.html — новости
- https://www.azstec.ru — должно перенаправлять на `azstec.ru`

Проверьте, что работает замок (HTTPS) и открываются картинки/каталог.

---

## После переезда (по желанию, для поисковиков)

1. **Яндекс.Вебмастер**: добавить сайт `https://azstec.ru`, подтвердить, отправить
   `https://azstec.ru/sitemap.xml`.
2. **Google Search Console**: то же самое (добавить домен, отправить карту сайта).

Файлы `robots.txt` и `sitemap.xml` уже лежат в проекте и указывают на `azstec.ru`.

---

## Если что-то пошло не так (откат)

- **Сайт не открывается по домену, но работает `amogusas.github.io/azstec-deploy/`** —
  значит, DNS ещё не догнал. Подождите.
- **Вернуть старый сайт:** в панели nic.ru верните прежние A/CNAME-записи, а в GitHub
  *Settings → Pages* очистите **Custom domain**. Файл `CNAME` при необходимости удалите
  и опубликуйте.
