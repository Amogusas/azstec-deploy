# Сайт АЗС Технологии — публикация на GitHub Pages

Сайт статический (HTML + JS + CSS, данные в `data/*.js`). Хостинг — **GitHub Pages**,
бесплатно, без карты. Публикация включена через ветку **main** (папка `/ (root)`), поэтому
достаточно закоммитить изменения — сайт обновится сам.

**Адрес сайта:** https://amogusas.github.io/azstec-deploy/

---

## ⚠️ Секреты

В корне лежит `opencode.json` с API-ключом. Он добавлен в `.gitignore`, поэтому в GitHub
**не попадает**. Не удаляйте эти строки из `.gitignore`:

```
opencode.json
opencode.txt
```

Проверить: на странице репозитория не должно быть файла `opencode.json`.

## Как обновить сайт (через GitHub Desktop)

1. Внесите изменения в файлы проекта либо скачайте свежие `data/news.js` / `data/users.js`
   из редактора (см. ниже) и положите их в папку `data/`.
2. Откройте **GitHub Desktop** (репозиторий `azstec-deploy`).
3. Слева появится список изменённых файлов → внизу введите описание → **Commit to main**.
4. Наверху нажмите **Push origin**.
5. Через ~1 минуту изменения появятся на сайте.

## Редактор материалов

Страница: https://amogusas.github.io/azstec-deploy/admin.html

- Вход по умолчанию: логин `admin`, пароль `admin123` (смените в разделе «Пользователи»).
- Роли: Администратор, Редактор, Автор. Права настраиваются каждому сотруднику отдельно.
- После правок нажмите **«Скачать data/news.js»** (и при необходимости
  **«Скачать data/users.js»**), положите файлы в папку `data/` и сделайте Commit → Push.

Редактор работает в браузере (данные в localStorage); чтобы правки увидели все посетители,
файлы нужно закоммитить, как описано выше.

## Домен azstec.ru (когда понадобится)

1. Репозиторий → **Settings → Pages → Custom domain** → введите `azstec.ru` → Save.
2. У регистратора домена (`azstec.ru` обслуживается на `nic.ru`) пропишите DNS-записи:

   **Для корня `azstec.ru`** — четыре A-записи:
   ```
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   ```

   **Для `www.azstec.ru`** — CNAME:
   ```
   www  →  Amogusas.github.io
   ```
3. Дождитесь проверки DNS и включите **Enforce HTTPS**.

Если домен привязывается впервые, GitHub может попросить подтвердить владение доменом —
добавьте предложенную **TXT**-запись и нажмите **Verify**.

## Настройки Pages (для справки)

- **Settings → Pages**
- **Source:** Deploy from a branch
- **Branch:** `main`, папка `/ (root)`
- Файл `.nojekyll` в корне отключает обработку через Jekyll (нужен, чтобы отдавалось «как есть»).

## Частые вопросы

**Сайт отдаёт «There isn't a GitHub Pages site here»?**
Публикация ещё не прошла — подождите 1–2 минуты и обновите страницу.

**Красный крестик в Actions?**
Он был из-за старого workflow, который мы удалили. Публикация идёт через ветку, Actions не нужен.

**Лимиты бесплатного тарифа:** ~1 ГБ на сайт, ~100 ГБ трафика в месяц, 10 сборок в час.
Для этого сайта — с большим запасом.
